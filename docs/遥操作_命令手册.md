## 2. 启动（每台一条命令）

**两条命令都会自动完成：起驱动 → 等驱动就绪 → 使能 → 回零 → 验证零位 → 进入对应模式**

### A 机（leader）

```bash
source ~/107/songlin/scripts/teleop_env.sh
ros2 launch piper_teleop teleop.launch.py role:=leader
```

自动依次完成：

| 步骤 | 日志关键字 |
|---|---|
| 起驱动 | `Agx_arm feedback is ready` |
| 使能 | `使能: Agx_arm enabled` |
| 回零 | `回零第 1 次: 最大偏差 X.XX°` |
| 进零力拖动 | `已进入零力拖动(leader)` |
| 就绪 | `==== leader 准备完成 ====` |

之后每 10 秒打印一次当前角度。

### B 机（follower）

```bash
source ~/107/songlin/scripts/teleop_env.sh
```

自动依次完成：

| 步骤 | 日志关键字 |

| 起驱动（60% 速度） | `speed_percent: 60` |

| 开控制门闸 | `控制门闸: External control gate opened` |
| 就绪 | `==== follower 准备完成 ====` |

## 3. 姿态检查（开桥前最后一道）

**任一台**执行：

```bash
python3 - <<'PY'
import math, time, rclpy
from rclpy.node import Node
from sensor_msgs.msg import JointState
rclpy.init(); n=Node("cmp")
A,F={},{}
n.create_subscription(JointState,"/leader/feedback/joint_states",lambda m:A.update(dict(zip(m.name,m.position))),10)
n.create_subscription(JointState,"/follower/feedback/joint_states",lambda m:F.update(dict(zip(m.name,m.position))),10)
t=time.time()
while (len(A)<6 or len(F)<6) and time.time()-t<12: rclpy.spin_once(n,timeout_sec=0.1)
if len(A)<6 or len(F)<6: print("读不到数据"); raise SystemExit
mx=0
for i in range(1,7):
    k=f"joint{i}"; d=math.degrees(F[k]-A[k]); mx=max(mx,abs(d))
    print(f"  {k} A={math.degrees(A[k]):+7.2f}  B={math.degrees(F[k]):+7.2f}  差={d:+6.2f}")
print(f"\n  最大差 {mx:.2f}°  {'✅ 可以开桥' if mx<15 else '❌ 先对齐'}")
PY
```

**最大差必须 < 15°**。超过时：

```bash
# A 一键回零（会自动恢复零力拖动状态）
ros2 service call /leader/leader_home std_srvs/srv/Empty "{}"
```

## 4. 起桥（任一台）

```bash
source ~/107/songlin/scripts/teleop_env.sh
ros2 launch piper_teleop teleop.launch.py role:=bridge
```

参数从 `install/piper_teleop/share/piper_teleop/config/teleop_params.yaml` 读，默认：

```yaml
rate: 50.0            # 转发频率
max_step_deg: 3.0     # 每帧最大变化 → 速度上限 150 °/s
alpha: 0.4            # 低通
watchdog_ms: 300.0    # 断流保护
init_max_diff_deg: 15.0
```

看到 `已对齐,开始转发(TELEOP)` 就可以拖 A 了。

## 5. 拖动

用手拖 A，B 跟随。桥每 5 秒打印：

```
已发 N 帧 | 跳过 M | 本帧滞后 X.XXdeg
```

| 现象 | 含义 |
|---|---|
| 跳过数很大 | 正常（手不动时不重复发） |
| 本帧滞后很大 | 拖太快，超出 150 °/s |
| 出现 `watchdog` | A 的数据断了 >300 ms |

**手感参考**：拖速 <50 °/s 时偏差约 2.8°；>150 °/s 会明显跟不上。

## 6. 停止（按顺序）

```
1. 起桥的终端：Ctrl-C
2. A / B 的 launch 终端：Ctrl-C
```

A 若还停在零力模式，先退出再关驱动：

```bash
ros2 service call /leader/restore_drag_mode std_srvs/srv/Empty "{}"
```

## 7. 故障处理

| 现象 | 原因 | 处理 |
|---|---|---|
| `收不到关节数据` | 驱动没连上臂（CAN/电源/急停） | 跑 `sudo can_up.sh`，看是否有 20 帧 |
| `使能失败` | 驱动刚起还没就绪 | 重跑 launch（会自动等 60 s） |
| `回零后仍有 X.X° 偏差` | 卡阻，或 `move_home` 只走一半 | 手工再调一次 `move_home`，或手拖到零位 |
| 桥报 `FAULT: 开局姿态差` | 两台差 >15° | 第 3 节对齐后再 `ros2 service call /teleop_reset std_srvs/srv/Trigger "{}"` |
| B 不动，桥在发 | 门闸没开 | 见附录 A.4 |
| `ros2 node list` 只有一个驱动 | domain/组播问题 | `echo $ROS_DOMAIN_ID` 应为 66；`ros2 daemon stop` 后重试；仍不行见附录 A.2 |

# 附录 A · 手工版（调试用）

封装节点失败、或想单步定位时，按下面手工执行。

## A.1 起驱动

```bash
# A
ros2 launch agx_arm_ctrl start_single_agx_arm.launch.py \
  namespace:=leader arm_type:=piper can_port:=can0 effector_type:=agx_gripper \
  speed_percent:=20 auto_enable:=false control_enabled:=false

# B
ros2 launch agx_arm_ctrl start_single_agx_arm.launch.py \
  namespace:=follower arm_type:=piper can_port:=can0 effector_type:=agx_gripper \
  speed_percent:=60 auto_enable:=false control_enabled:=false
```

## A.2 通信排障

```bash
echo $ROS_DOMAIN_ID          # 必须 66
ros2 daemon stop
ros2 node list               # 应看到两个驱动节点
```

组播被挡时加静态对等：

```bash
# A 机
export ROS_STATIC_PEERS="192.168.3.179"
# B 机
export ROS_STATIC_PEERS="192.168.3.232"
```

## A.3 使能 + 回零（顺序不能反）

```bash
# A
ros2 service call /leader/enable_agx_arm std_srvs/srv/SetBool "{data: true}"
ros2 service call /leader/move_home std_srvs/srv/Empty "{}"

# B
ros2 service call /follower/enable_agx_arm std_srvs/srv/SetBool "{data: true}"
ros2 service call /follower/move_home std_srvs/srv/Empty "{}"
```

> ⚠️ **未使能时 `move_home` 静默失败**（只打一行 warn，不返回错误）。
> 驱动源码：`elif not self.enable_flag: warn("cannot move to home position")`

> ⚠️ `move_home` 有时**只走一半就报成功**，必须读角度确认。

## A.4 进入模式

```bash
# A:零力拖动
ros2 service call /leader/leader_mode std_srvs/srv/Empty "{}"

# B:开控制门闸(不开则桥在发但 B 不动)
ros2 service call /follower/control_enable std_srvs/srv/SetBool "{data: true}"
```

## A.5 单独起桥

```bash
ros2 run piper_teleop teleop_bridge --ros-args \
  -p src_topic:=/leader/feedback/joint_states \
  -p dst_topic:=/follower/control/joint_states \
  -p follower_fb_topic:=/follower/feedback/joint_states \
  -p rate:=50.0 -p max_step_deg:=3.0 -p alpha:=0.4 \
  -p watchdog_ms:=300.0 -p init_max_diff_deg:=15.0 \
  -p passthrough_gripper:=true
```

## A.6 单独跑准备节点

```bash
# 带超时,便于快速失败
ros2 run piper_teleop teleop_setup --ros-args \
  -p role:=leader -p service_timeout_s:=10.0 -p monitor_period_s:=0
```

`monitor_period_s:=0` 表示准备完就退出（不进入周期打印）。
