# 遥操作 · 快速上手

> A = 手拖端（leader）　B = 跟随端（follower）
> A `192.168.3.232`　B `192.168.3.179`

## 前置（两台都做）

- [ ] USB-CAN 插好
- [ ] 机械臂 24V 上电
- [ ] 急停按钮弹起
- [ ] 周围清空（尤其 B）

---

## 1. 激活 CAN（两台，需要 sudo）

```
$ sudo ~/107/songlin/scripts/can_up.sh
```

→ `[ OK ] 20 帧` 和 `[ OK ] 检测到状态/关节反馈帧`

---

## 2. 加载环境（**每个新终端**都要）

```
$ source ~/107/songlin/scripts/teleop_env.sh
```

→ `[teleop_env] DOMAIN=66  RANGE=SUBNET  WS=/home/xxx/107/songlin`

---

## 3. A 机 · 终端 A1

```
$ source ~/107/songlin/scripts/teleop_env.sh
$ ros2 launch piper_teleop teleop.launch.py role:=leader
```

→ 等到 `==== leader 准备完成 ====`

**然后用手按下机械臂上的【拖动/示教按键】，LED 亮起**

---

## 4. B 机 · 终端 B1

```
$ source ~/107/songlin/scripts/teleop_env.sh
$ ros2 launch piper_teleop teleop.launch.py role:=follower
```

→ 等到 `==== follower 准备完成 ====`

---

## 5. 起桥 · A 机新终端 A2

```
$ source ~/107/songlin/scripts/teleop_env.sh
$ ros2 launch piper_teleop teleop.launch.py role:=bridge
```

→ 等到 `已对齐,开始转发(TELEOP)`

---

## 6. 拖

拖 A 的机械臂，B 跟随。

桥每 5 秒打印一次：`已发 N 帧 | 跳过 M | 本帧滞后 X.XXdeg`
本帧滞后 **0.1~4°** 属正常。

---

## 停止（按顺序）

1. 终端 **A2** 按 Ctrl-C（停桥）
2. 终端 **A1** / **B1** 按 Ctrl-C（停驱动）
3. A 的拖动按键 LED 若还亮着 → **按一下关掉**

---

## 出问题

→ 看 `docs/遥操作_详细说明.md` 第四章「故障排查」

## 绝对不要做

```
ros2 service call /leader/leader_mode std_srvs/srv/Empty "{}"     ← 禁止
```

它发的 `0xFA` 会被机械臂持久化，导致下次上电臂不进反馈模式、驱动彻底连不上。
