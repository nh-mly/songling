3. 姿态检查 (任一台,A2 或 B2 新终端)
--------------------------------------------------------------------------------
python3 - <<'PY'
import math, time, rclpy
from rclpy.node import Node
from sensor_msgs.msg import JointState
rclpy.init(); n=Node("cmp")
A,F={},{}
n.create_subscription(JointState,"/leader/feedback/joint_states",lambda m:A.update(dict(zip(m.name,m.position))),10)
n.create_subscription(JointState,"/follower/feedback/joint_states",lambda m:F.update(dict(zip(m.name,m.position))),10)
t=time.time()
while (len(A)<6 or len(F)<6) and time.time()-t<12: rclpy.spin_once(n,timeout_sec=0.1)
if len(A)<6 or len(F)<6: print("读不到数据"); raise SystemExit
mx=0
for i in range(1,7):
    k=f"joint{i}"; d=math.degrees(F[k]-A[k]); mx=max(mx,abs(d))
    print(f"  {k} A={math.degrees(A[k]):+7.2f}  B={math.degrees(F[k]):+7.2f}  差={d:+6.2f}")
print(f"\n  最大差 {mx:.2f}°  {'可以开桥' if mx<15 else '先对齐'}")
PY

  判据: 最大差 < 15° 才能起桥

================================================================================
今天踩到的坑(详细版见 docs/踩坑记录.md #31~#36)
================================================================================

① 0xFA 会被持久化(最坑的一个)
   现象: 一上电臂就"飘"(重力补偿),驱动报 Failed to get firmware version,
         CAN 帧率几乎 0。
   原因: 之前调用过 leader_mode,发了 0x470 + 0xFA,控制器记进了 Flash。
         Leader 模式下臂把关节角当控制帧(0x15x)广播,不再发反馈帧(0x2Ax)。
   恢复: cansend can0 470#FC00000000000000
         注意 0x470#00 是空操作(协议里 0x00 = 无效),不能复位!

② move_home 服务不可靠
   现象: 日志报 moved to home position successfully,但臂一动不动。
   原因: 驱动 _wait_motion_done() 把"还没开始动"当成"已到位"。
   做法: 用 control/move_j 发零位,或重复调用 move_home。

③ teleop_env.sh 在 zsh 下静默失效
   现象: 打印 DOMAIN=66 看着正常,但 ros2 launch 报 Package not found。
   原因: 脚本用 ${BASH_SOURCE[0]} 推导路径,zsh 里这个变量是空的。
   修法: 已改为固定路径 $HOME/107/songlin + 区分 setup.zsh / setup.bash。
   自检: ros2 pkg prefix piper_teleop 必须有输出。

④ Device is DOWN 不是臂坏了
   那是 socketcan 接口没 up,跑 can_up.sh 即可。

⑤ 关节读数超限/跳变时,先看帧类型
   timeout 3 candump can0 | awk '{print $2}' | sort | uniq -c
     有 2A1~2A8        -> 反馈正常,数值可信
     只有 151/155/156/157 -> 臂在 Leader 模式,数值不可信(见 ①)
     什么都没有         -> 接口或物理连接问题
