# 遥操作 v1.0 · 命令手册

> 从通信开始，按顺序执行。终端编号对应实际窗口。
> **A = leader（手拖）**，IP `192.168.3.232`
> **B = follower（跟随）**，IP `192.168.3.179`

---

## 0. 一次性准备（每台机器，只做一次）

### 0.1 确认工作区能编译

```bash
cd ~/107/songlin && ./scripts/build.sh
```

### 0.2 确认 Python 依赖

```bash
python3 -c "import pyAgxArm, can; print('pyAgxArm', pyAgxArm.__version__, '| python-can', can.__version__)"
```

期望 `pyAgxArm 1.0.0 | python-can 4.6.1`。

### 0.3 建立通信用环境脚本

```bash
cat > ~/107/songlin/scripts/teleop_env.sh <<'EOF'
# 遥操作环境：跨机通信
export ROS_DOMAIN_ID=66
export ROS_AUTOMATIC_DISCOVERY_RANGE=SUBNET
export LC_NUMERIC=en_US.UTF-8
. /opt/ros/jazzy/setup.bash 2>/dev/null
_here="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
[ -f "$_here/install/setup.bash" ] && . "$_here/install/setup.bash"
echo "[teleop_env] DOMAIN=$ROS_DOMAIN_ID  RANGE=$ROS_AUTOMATIC_DISCOVERY_RANGE"
EOF
chmod +x ~/107/songlin/scripts/teleop_env.sh
```

## 1. 通信：建立并验证跨机连接

### 1.1 每台机器都设定同一 domain

**A 机任一终端**、**B 机任一终端**，各执行一次：

```bash
source ~/107/songlin/scripts/teleop_env.sh
```

必须看到：

```
[teleop_env] DOMAIN=66  RANGE=SUBNET
```

> `DOMAIN=66` 两台必须一致；`RANGE=SUBNET` 允许跨机发现。
> 这一步替代了原来的 `env.sh`（那个设的是 `LOCALHOST`，只在本机可见）。

### 1.2 验证跨机发现

先在两台各起一个驱动（见第 2、3 步），然后在**任一台**执行：

```bash
ros2 node list
```

应看到 **两个** 驱动节点：

```
/leader/agx_arm_ctrl_single_node
/follower/agx_arm_ctrl_single_node
```

只看得到一个 → 见第 9 节排障。

### 1.3 备用：组播被挡时走静态对等

WiFi 的 AP 常丢组播。若 1.2 看不到对方，在**两台**都加对方 IP：

```bash
# A 机（填 B 的 IP）
export ROS_STATIC_PEERS="192.168.3.179"
ros2 daemon stop

# B 机（填 A 的 IP）
export ROS_STATIC_PEERS="192.168.3.232"
ros2 daemon stop
```

然后重新跑第 2、3 步。

## 2. A 机：启动 leader 驱动

**终端 A1**（保持不动，别 Ctrl-C）

```bash
source ~/107/songlin/scripts/teleop_env.sh
ros2 launch agx_arm_ctrl start_single_agx_arm.launch.py \
  namespace:=leader arm_type:=piper can_port:=can0 effector_type:=agx_gripper \
  speed_percent:=20 auto_enable:=false control_enabled:=false
```

等到这行出现：

```
Agx_arm feedback is ready, control is now enabled
```

> `namespace:=leader` 让话题变成 `/leader/feedback/joint_states`、服务 `/leader/leader_mode`。

## 5. A 机：使能 + 进入零力拖动

**终端 A2**（新开）

```bash
source ~/107/songlin/scripts/teleop_env.sh
```

```bash
ros2 service call /leader/enable_agx_arm std_srvs/srv/SetBool "{data: true}"
```

```bash
ros2 service call /leader/leader_mode std_srvs/srv/Empty "{}"
```

期望：

```
message='Agx_arm enabled'
message='Leader mode ON (zero-force drag)'
```

此时 A 的机械臂变"轻"，一根手指能推动，松手停在原地。

> 顺序不能反：**先 enable 再 leader_mode**。零力模式同样需要电机出力抵消重力。

## 6. 姿态对齐检查（关键，别跳）

桥是**绝对角度镜像**，两台姿态差太大时 B 会猛扫。

**终端 A2 或 B2** 任一台执行：

```bash
python3 - <<'PY'
import math, time, rclpy
from rclpy.node import Node
from sensor_msgs.msg import JointState
rclpy.init(); n=Node("cmp")
A,F={},{}
n.create_subscription(JointState,"/leader/feedback/joint_states",lambda m:A.update(dict(zip(m.name,m.position))),10)
n.create_subscription(JointState,"/follower/feedback/joint_states",lambda m:F.update(dict(zip(m.name,m.position))),10)
t=time.time()
while (len(A)<6 or len(F)<6) and time.time()-t<12: rclpy.spin_once(n,timeout_sec=0.1)
if len(A)<6 or len(F)<6: print("读不到数据"); raise SystemExit
mx=0
for i in range(1,7):
    k=f"joint{i}"; d=math.degrees(F[k]-A[k]); mx=max(mx,abs(d))
    print(f"  {k} A={math.degrees(A[k]):+7.2f}  B={math.degrees(F[k]):+7.2f}  差={d:+6.2f}")
print(f"\n  最大差 {mx:.2f}°  {'✅ 可以开桥' if mx<15 else '❌ 先对齐'}")
PY
```

**最大差 < 15°** 才能进行下一步。超过就：

- 手拖 A 靠近 B 的姿态（A 是零力模式，很轻），或
- A 机执行一键回零：

```bash
ros2 service call /leader/leader_home std_srvs/srv/Empty "{}"
```

> `leader_home` 让 A 受控回零，默认 8 秒后自动恢复零力拖动状态。
> 可用参数调整：`-p leader_home_seconds:=12.0`（在驱动 launch 上加）。

## 7. A 机：启动桥

**终端 A2**（或 B2 也行）

```bash
source ~/107/songlin/scripts/teleop_env.sh
```

```bash
ros2 run piper_teleop teleop_bridge --ros-args \
  -p src_topic:=/leader/feedback/joint_states \
  -p dst_topic:=/follower/control/joint_states \
  -p follower_fb_topic:=/follower/feedback/joint_states \
  -p rate:=50.0 -p max_step_deg:=3.0 -p alpha:=0.4 \
  -p watchdog_ms:=300.0 -p init_max_diff_deg:=15.0 \
  -p passthrough_gripper:=true
```

启动日志应包含：

```
bridge /leader/feedback/joint_states -> /follower/control/joint_states @ 50 Hz
已对齐,开始转发(TELEOP)
```

如果打印 `FAULT: 开局姿态差 ...` → 回到第 6 步对齐。

## 8. 开始拖动

用手拖 A，B 跟随。桥会每 5 秒打印一次统计：

```
已发 N 帧 | 跳过 M | 本帧滞后 X.XXdeg
```

| 现象 | 含义 |
|---|---|
| `跳过` 数很大 | 正常：手不动时桥不重复发 |
| `本帧滞后` 很大 | 拖太快，超出限速上限 |
| 打印 `watchdog` | A 的数据断了 >300 ms |

## 9. 正常停止（按这个顺序）

```
1. 终端 A2：Ctrl-C 停桥
2. A：退出零力拖动
3. B：保持最后位置（无需操作）
4. 需要归位时再各自 move_home
```

退出 A 的零力拖动：

```bash
ros2 service call /leader/restore_drag_mode std_srvs/srv/Empty "{}"
```

驱动本身（A1 / B1 两个终端）按 Ctrl-C 关闭。

## 10. 关键参数一览

| 参数 | 默认 | 说明 |
|---|---|---|
| `rate` | 50 | 转发频率；WiFi 下 50 稳定 |
| `max_step_deg` | 3.0 | 每帧最大变化；上限速度 = `max_step × rate` |
| `alpha` | 0.4 | 一阶低通，越小越平滑但越滞后 |
| `watchdog_ms` | 300 | 超过则暂停转发（B 保持原位） |
| `init_max_diff_deg` | 15 | 开局姿态差上限，超过拒绝启动 |
| `max_vel_deg_s` | 600 | A 的角速度超过此值判为异常并锁死 |
| `joint_offset_deg` | `[0]*6` | 零位补偿，两台零位有固定差时用 |
| `passthrough_gripper` | true | 是否同步夹爪 |

**速度上限换算**：`max_step_deg × rate`
- 3.0 × 50 = **150 °/s**
- 3.0 × 100 = 300 °/s（需要 WiFi 稳定）

## 11. 故障处理

### 桥报 FAULT

```bash
ros2 service call /teleop_reset std_srvs/srv/Trigger "{}"
```

先确认机械臂周围安全，再 reset（reset 会重新对齐，不会跳）。

### B 不动，但桥在发

门闸没开：

```bash
ros2 service call /follower/control_enable std_srvs/srv/SetBool "{data: true}"
```

### 看不到对方的节点

```bash
# 1. 确认 domain 一致（两台都要 66）
echo $ROS_DOMAIN_ID

# 2. 清缓存
ros2 daemon stop

# 3. 还不行就加静态对等（见 1.3）
```

### 驱动起来就报 `Failed to get firmware version` / `Device is DOWN`

CAN 掉线：

```bash
sudo ~/107/songlin/scripts/can_up.sh
```

## 12. 一页速查（最常用的几条）

```bash
# 通信
source ~/107/songlin/scripts/teleop_env.sh

# A 进零力拖动
ros2 service call /leader/enable_agx_arm std_srvs/srv/SetBool "{data: true}"
ros2 service call /leader/leader_mode std_srvs/srv/Empty "{}"

# A 一键回零（回零后自动恢复拖动）
ros2 service call /leader/leader_home std_srvs/srv/Empty "{}"

# B 使能 + 开门闸
ros2 service call /follower/enable_agx_arm std_srvs/srv/SetBool "{data: true}"
ros2 service call /follower/control_enable std_srvs/srv/SetBool "{data: true}"

# 起桥
ros2 run piper_teleop teleop_bridge --ros-args \
  -p max_step_deg:=3.0 -p alpha:=0.4 -p watchdog_ms:=300.0

# 清故障
ros2 service call /teleop_reset std_srvs/srv/Trigger "{}"
```
