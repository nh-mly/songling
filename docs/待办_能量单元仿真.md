# 待办 · 能量单元仿真

> **触发词**：用户说「能量单元仿真」= 就是这件事。
> 状态：**未开始**，等用户提供 URDF。

## 目标

把「能量单元」作为一个物体加进仿真，让机械臂能**抓住它**：

```
MuJoCo: 能量单元作为自由刚体放在桌上 → 夹爪靠近 → 合爪 → 带走
MoveIt: 把它加进规划场景 → 规划时避开/对准
```

## 开工前必须问用户要的信息

| # | 问什么 | 为什么 |
|---|---|---|
| 1 | **URDF 文件在哪**（或 mesh 路径） | 没有模型无从下手 |
| 2 | **单位是米还是毫米** | 有些导出是 mm，差 1000 倍，错了整个尺寸不对 |
| 3 | **摆在桌上什么位置**（相对底座中心 x/y，cm） | 规划目标点 |
| 4 | **朝向**（绕 Z 转多少度） | 决定夹爪从哪个方向接近 |
| 5 | **要不要能夹起来**（自由刚体 / 固定障碍物） | 决定加不加 `<freejoint>` |
| 6 | 大概**尺寸**（长宽高或直径×高，mm） | 决定夹爪开度、接近姿态、是否超 100 mm 上限 |

## 计划做的事

1. 读 URDF，确认 mesh 格式（stl/dae/obj）与惯量、质量
2. 写 `piper_tools/add_object`：
   - `--urdf <path> --xyz X Y Z --yaw D --dynamic/--static`
   - 解析 URDF 的 link/mesh → `MoveIt CollisionObject`（碰撞检测）
   - 生成 MJCF body（mesh + inertial + freejoint）→ 注入 `piper_mujoco/mjcf/scene.xml`
3. 在 MuJoCo 里验证：能看到、能夹住、夹住后跟着动
4. 在 MoveIt 里验证：规划路径避开它、目标点在它上方

## 已知约束（会影响方案）

| 约束 | 数值 | 影响 |
|---|---|---|
| 夹爪最大开度 | 100 mm（命令值比实际大 ~0.8 mm） | 物体宽度 > 95 mm 就夹不住 |
| 工具朝下时的可达范围 | 法兰 z ≥ 0.16，指尖 z ≥ 0.01 | 太高的物体要从侧面夹 |
| 水平夹持 | 只能在 z ≥ 0.25 规划 | 矮物体不能用水平姿态 |
| 重复定位误差 | 5–10 mm（真机） | 对中余量小于 5 mm 时容易夹偏 |
